# PDF 小工具 (PDF Tool)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Platform: Web](https://img.shields.io/badge/Platform-Web-blue.svg)

這是一個基於瀏覽器、純前端實現的 PDF 處理工具。我們專注於提供一個**極速、美觀且絕對私密**的解決方案，讓您在不需要安裝笨重軟體或上傳敏感檔案到雲端的情況下，輕鬆完成日常 PDF 工作。

## ✨ 為什麼選擇此工具？

-   **🔒 絕對隱私**：所有檔案處理都在您的瀏覽器本機端 (Client-side) 完成。檔案不會離開您的電腦，沒有任何數據會被上傳到伺服器。
-   **⚡ 極速反應**：省去上傳與下載的時間，處理速度僅取決於您的電腦效能。
-   **🎨 莫蘭迪美學**：採用溫潤、優雅的 Morandi 配色設計，提供舒適且不壓迫的操作介面。
-   **📦 零安裝**：只需一個 HTML 檔案，透過現代瀏覽器即可開啟使用。

## 🛠 核心功能

1.  **合併 (Merge)**：
    -   批次上傳多個 PDF。
    -   直覺調整檔案順序。
    -   一鍵合併為單一文件。
2.  **旋轉 (Rotate)**：
    -   支援 90°、180°、270° 旋轉。
    -   可指定特定頁碼範圍（例如：`1, 3-5`）。
3.  **分割 (Split)**：
    -   強大的範圍分組功能（例如：輸入 `1-3; 5-8` 可產出兩個檔案）。
    -   支援「一鍵每頁一檔」模式。
    -   支援 ZIP 打包下載，方便管理多個分割檔。
4.  **圖片化壓縮 (Rasterize)**：
    -   將 PDF 頁面渲染為影像後重新建構，顯著減小掃描檔大小。
    -   支援自訂 DPI、JPEG 品質及灰階轉換。
    -   *註：此操作會使 PDF 失去文字搜尋功能。*
5.  **結構化壓縮 (Structural)**：
    -   透過重建頁面與清理 Metadata 來優化檔案結構。
    -   保留原始向量與文字，畫質不減損。
6.  **頁面插入 (Insert)**：
    -   精準將一個 PDF 的特定頁面插入到另一個文件的指定位置（開頭、結尾或特定頁碼後）。
7.  **操作日誌 (Live Log)**：
    -   透明化顯示處理進度與詳細結果，方便追蹤。

## 🚀 快速開始

1.  **下載**：Clone 或下載本專案。
2.  **開啟**：直接使用 Chrome、Edge 或 Safari 開啟 `PDF_tool.html`。
3.  **操作**：
    -   選擇功能分頁。
    -   拖放 PDF 檔案至虛線區域。
    -   設定參數後點擊執行按鈕。
    -   處理完成後將自動觸發下載。

## 🧰 技術架構

-   **核心庫**：
    -   [pdf-lib](https://pdf-lib.js.org/)：負責 PDF 的建立、修改與頁面操作。
    -   [pdf.js](https://mozilla.github.io/pdf.js/)：負責 PDF 的渲染與影像化處理。
    -   [JSZip](https://stuk.github.io/jszip/)：處理多檔案下載時的壓縮打包。
-   **設計**：純原生 CSS + HTML5，採用 CSS Variables 管理莫蘭迪調色盤。
-   **架構**：遵循 3-Layer 結構（UI / Application / Core），確保邏輯清晰易於維護。

## ⚠️ 聲明與限制

-   本工具無法處理受加密 (Password-protected) 或 DRM 保護的 PDF 檔案。
-   對於極大型檔案，處理速度與成功率取決於瀏覽器的記憶體限制。
-   建議在使用前自行備份原始檔案。
