# PDF 小工具測試計畫

## 1. 測試目標
驗證 PDF 小工具的核心功能：合併、旋轉、分割，確保在瀏覽器環境下運作正常且不損壞 PDF 內容。

## 2. 測試環境
- 瀏覽器：Chrome / Edge (最新版)
- 測試檔案：`test/assets/staying-ahead-in-the-age-of-ai.pdf` (共 15 頁)

## 3. 測試案例 (Manual Test Cases)

### TC-001: PDF 旋轉功能
- **步驟**:
    1. 切換至「旋轉」標籤。
    2. 上傳測試檔案。
    3. 選擇第一頁，點擊「右轉 90 度」。
    4. 點擊「下載旋轉後的 PDF」。
- **預期結果**: 下載的 PDF 第一頁應為橫向，其餘頁面維持原樣。

### TC-002: PDF 分割功能 (範圍)
- **步驟**:
    1. 切換至「分割」標籤。
    2. 上傳測試檔案。
    3. 設定範圍為 `1-3, 5`。
    4. 點擊「下載分割後的 PDF」。
- **預期結果**: 下載的 PDF 應包含原檔的第 1, 2, 3, 5 頁，總計 4 頁。

### TC-003: PDF 合併功能
- **步驟**:
    1. 切換至「合併」標籤。
    2. 上傳測試檔案兩次。
    3. 點擊「合併並下載」。
- **預期結果**: 下載的 PDF 應包含 30 頁 (15 + 15)。

## 4. 自動化測試規劃
- **單元測試**: 測試檔名處理、範圍解析邏輯。
- **整合測試**: 使用 Playwright (未來擴充) 模擬使用者上傳與下載操作。
